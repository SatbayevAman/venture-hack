# Разметка реальных работ

1. Сфотографируйте решение (одна задача — одно фото), положите в эту папку, например `eval/photos/01.jpg`.
2. Добавьте строку в `labels.csv`: путь к фото, тип (`equation`/`expression`), условие, строки решения через ` | ` — **ровно как написано в тетради, с ошибками**, номер первой неверной строки (0 — если всё верно) и тег ошибки.
3. `python evaluate.py` — точность проверки на эталонных строках; `python evaluate.py --ocr` — плюс распознавание фото (нужен ключ API).

Только с согласия одноклассников; в файл — без имён.
